# 旅行家持续双向远门

> 适用版本：`0.9.29-1.20.1` · 状态：`playable candidate`

## 快速使用

1. 用原版指南针对磁石右键，建立持久空间标记。
2. 输入 `/pm travel` 检查目标、名称、20 秒门时限、权限和黑名单数量。
3. 用 `/pm travel name <名称>` 命名，或用 `/pm travel name clear` 清除；名称最多 32 个 Unicode 字符。
4. 用 `/pm travel access private|party|public` 设置访问模式。
5. 用 `/pm travel block <在线玩家>`、`unblock <在线玩家>` 和 `blocked` 管理最多 32 人的持久黑名单。
6. 旅行家序列 5 手持有效标记按 `U`。
7. 源点和磁石处各出现一扇门；需要通行的人主动走入门体。
8. `/pm travel doors` 查看当前端点，`/pm travel close` 提前撤销自己的双端门。

开门不会立即传送任何人。实际走入门才是最终同意。

## 名称、权限与黑名单

- 名称写入指南针 NBT；服务端移除格式码、控制字符和多余空白。两端门显示同一快照名称。
- `/pm travel access private`：只有门主能通过。
- `/pm travel access party`：默认模式；门主和开门时同一原版 `/team` 队伍成员可通过。
- `/pm travel access public`：任意存活、非旁观玩家可通过。
- 黑名单优先于 `party` 和 `public`；门主始终保留通行权。
- 权限与队伍在开门时快照；黑名单也写入门 NBT，但 block/unblock 会立即更新当前门。

## 领地与安全

- 服务端先验证维度、世界边界、真实磁石、源门/目标门空间和安全落点，再扣灵性。
- 源端、目标端和每次穿门目标都会检查原版出生点保护。
- 三个动作都会发布可取消 `TravelerDoorTerritoryEvent`，供第三方领地 Mod 接入。
- 领地拒绝发生在扣费或移动前；权限后来变化时，玩家留在原地。
- 两端都生成成功后才开始主持冷却；第二端失败会清除第一端并退款。
- 外人或被拉黑者触碰门只收到限频提示，不扣资源、不写冷却。
- 穿门后 2 秒内不能被目标端弹回；每名门主同时只保留最新一对门。

当前完成的是稳定 Forge 兼容契约，不代表已经完成 FTB Chunks 等具体适配器。

管理员可用 `/pm travel admin doors <在线玩家>` 与 `/pm travel admin close <在线玩家>` 查询或撤销
指定在线门主的已加载端点；普通玩家不能跨门主操作。
