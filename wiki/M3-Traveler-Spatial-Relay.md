# 旅行家持续双向远门

> 适用版本：`0.9.25-1.20.1` · 状态：`code_ready`

## 快速使用

1. 用原版指南针对磁石右键，建立持久空间标记。
2. 输入 `/pm travel` 检查目标、20 秒门时限和当前权限。
3. 可选：输入 `/pm travel access private|party|public`。
4. 旅行家序列 5 手持有效标记按 `U`。
5. 源点和磁石处各出现一扇门；需要通行的人主动走入门体。

开门不会立即传送任何人。实际走入门才是最终同意。

## 费用与时间

| 项目 | 数值 |
|---|---:|
| 基础费用 | 80 灵性 |
| 开门支持者 | +10/人，最多 3 人 |
| 支持者条件 | 四格内潜行、同维、持相同磁石标记 |
| 门寿命 | 20 秒 |
| 主持开门冷却 | 1,800 秒 |
| 非门主支持冷却 | 60 秒 |
| 穿门反回弹 | 2 秒 |
| 抵达保护 | 3 秒抗性 II |

支持者只影响开门费用和邀请提示。没有主动走入门体的玩家不会移动。

## 权限

- `/pm travel access private`：只有门主能通过。
- `/pm travel access party`：默认模式；门主和开门时同一原版 `/team` 队伍成员可通过。
- `/pm travel access public`：任意存活、非旁观玩家可通过。

队伍与权限在开门时快照。门存在期间改队或切换偏好不会改变已经生成的门；下一次开门使用新设置。
门主在三种模式下都可通行。

## 安全与失败

- 服务端先验证维度、世界边界、真实磁石、源门/目标门空间和安全落点，再扣灵性。
- 两端都生成成功后才开始主持冷却；第二端失败会清除第一端并退款。
- 穿门时再次检查目标安全；磁石附近后来被堵住时，玩家留在原地。
- 外人触碰私人或队伍门只会收到限频提示，不扣资源、不写冷却。
- 穿门后 2 秒内不能被目标端弹回。
- 每名门主同时只保留最新一对门；指南针与磁石不会被消耗。

## 单人和多人

- 单人：使用默认 `party` 也可自行往返。
- 原版队伍：队长先用 `/team` 建队，再保持 `party` 权限。
- 临时公开撤离：开门前切到 `public`；完成后切回 `party` 或 `private`，已开的门不会追溯变化。
- 不想参与：不要走入门体；站在附近不会被强制传送。
