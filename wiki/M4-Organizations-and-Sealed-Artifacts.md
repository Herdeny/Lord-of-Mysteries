# M4 组织与封印物

> 当前版本：`0.9.34-1.20.1` · M4 机器可玩范围完成
> 当前范围：12 个组织、6 类行动、3 名轮值联络员、24/24 件封印物。
> 最后更新时间与时区以 Wiki 首页同步的 `project-status.json` 为准。

## 快速开始

```text
/pm m4
/pm organization
/pm organization strategy
/pm organization claim <1-3>
/pm organization submit
/pm artifact catalog
/pm artifact borrow <封印物ID>
/pm artifact stabilize
/pm artifact return
```

也可直接与迷雾城前哨的三名轮值联络员交互。联络员按晨间会商、公开接洽、夜间值守换位，展示对应组织、风险、当日行动和本周战略；交互可直接接取。命令入口始终可用。

## 组织世界

- 七个教会：长夜守望、风暴灯塔、炉心与机械、烈阳圣坛、知识圣堂、丰壤母庭、铁誓战争教团。
- 五个隐秘组织：极昼秘仪会、心智炼成社、赤蔷薇学社、密文会、拾荒者行会。
- 每个组织都有公开身份、隐秘单位、教义、资源、领地、关系和策略权重。
- 每 7 个游戏日制定一次独立周战略；每天产生三项不重复行动。
- 玩家不在线时行动仍会自主结算；普通停服跨日逐日追赶，极端管理员跳时有界重放完整上周与当前周，避免卡服并精确保留上周摘要和本周动量。
- 多名玩家可参与同一公共行动，但任务、进度、材料和奖励按 UUID 隔离。

| 行动 | 完成方式 |
|---|---|
| 夜间巡查 | 前哨 64 格内击败 3 只怪物 |
| 封印物转运 | 携带登记封印物回前哨提交 |
| 异端材料复核 | 携带动态证据卷宗 |
| 灾后救济 | 携带 8 个面包；成功提交时才消耗 |
| 高层议事 | 序列 5 或更高，且对应组织声望至少 8 |
| 秘密招募 | 对应组织声望至少 4，并携带知识抄本 |

`leaked` 实例禁止直接归还。备齐对应材料后执行 `/pm artifact stabilize`，进入 `recovered` 后再回库。任何失败校验都不吞材料。

## 保管状态与多人安全

- `borrowed`：责任人正常借用；
- `leaked`：逾期、过量或污染越界，只能稳定；
- `recovered`：换手找回或泄漏已稳定，只能回库；
- `returned`：已归还并释放世界唯一库位；
- `abused`：复制或状态冲突，全部隔离，需管理员审计。

台账记录实例、责任人、持有人、维度、坐标、污染、次数、期限和事故。离线、掉落和重启不会暂停期限；同玩家复制和跨玩家同 tick 双持都会隔离。普通玩家只看本人负责/持有记录，全局位置和退役只允许权限 2。

```text
/pm artifact admin ledger
/pm artifact admin retire <实例UUID>
```
