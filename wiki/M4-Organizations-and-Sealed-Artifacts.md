# M4 组织与封印物

> 当前版本：`0.9.31-1.20.1` · 里程碑：M4 `active`  
> 最后更新时间与时区以 Wiki 首页同步的 `project-status.json` 为准。  
> 当前范围：12 个组织、6 类自主行动、7/24 件可玩封印物。

## 快速开始

```text
/pm m4
/pm organization
/pm organization claim <1-3>
/pm organization submit
/pm organization abandon
/pm artifact
/pm artifact catalog
/pm artifact borrow <封印物ID>
/pm artifact stabilize
/pm artifact return
```

组织每天按世界种子、游戏日和全服神秘暴露自主产生三项不重复行动。玩家不在线也不影响行动刷新；每名玩家的接取、击杀进度、提交和奖励独立保存。

## 保管状态

- `borrowed`：责任人正常借用；
- `leaked`：逾期、超出安全次数或污染达到阈值；
- `recovered`：由非责任人找回，或泄漏已稳定；
- `returned`：已回库并释放唯一库位；
- `abused`：复制、同刻双持或严重状态冲突，必须管理员审计。

台账持久记录实例、责任人、持有人、维度、坐标、污染、使用次数、借出/到期日和事故。离线或掉落不会暂停借期。

泄漏恢复需要安神香×1和纯水×1，然后执行 `/pm artifact stabilize`，最后回前哨 `/pm artifact return`。

管理员只在确认复制/坏档后使用：

```text
/pm artifact admin ledger
/pm artifact admin retire <实例UUID>
```

退役不会把复制物变成合法物品；它们继续隔离，只释放库位。

## 多人和权限

- 多人可接取同一公共行动，但进度与奖励完全隔离；
- 封印物不会按队伍复制，换手会进入回收流程；
- 同玩家复制和跨玩家同刻双持都会隔离；
- 来客面具不会绕过旅行家组织门、领地或任何权限检查；
- 封印物转运只发组织任务奖励，不重复发直接归还奖励；
- 失败提交不吞面包、材料或封印物。
