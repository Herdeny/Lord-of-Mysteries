# 1.0 验收矩阵：目标，不是完成报告

文档修订：1.0-design-r1 · 2026-11-09。以下48项是待实施/持续回归的目标矩阵；现有局部自动测试通过不代表整行通过。每次验收记录SHA、硬件、世界/种子、步骤、预期/实际、原始日志、操作者与遗留风险。生产服测试先复制隔离世界，不修改正式存档。

## 失败和反证

- 正向不代替负向；拒绝时同时核对操作者、目标、世界没有未授权变化。
- 随机性采用固定seed回归与独立统计，不靠多跑几次碰巧过关。
- 关键回归保留修复前失败证据。0.9.39偷窃库存已恢复旧扣料顺序复现失败；这不证明全部技能都无缺陷。
- 自动化玩家不是两名真人网络体验；未做兼容、真人或长时测试须明确标未验收。
- 不用重试、跳过断言、隐藏日志、关闭工作流掩盖缺陷。
