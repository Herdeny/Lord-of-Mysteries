# 灵界生态观察与手账（0.9.37）

## 一分钟上手

1. 备好航路灯与灵界罗盘，以 `/pm spirit enter theatre` 等现有入口开始远征。
2. 用 `/pm spirit compass` 读方向，再用 `/pm spirit navigate north|east|south|west` 行进。
3. 遭遇出现后，持**调查员残缺手稿**右键它，或使用 `/pm spirit study`。观察会留下线索，不结束遭遇。
4. 根据线索选择观察、回避、帮助、交易；用 `/pm spirit journal` 回看个人图鉴进度。
5. 六段航路完成后安全撤离；失败时先查看 `/pm spirit status`，必要时用 `/pm spirit recover`。

| 手持 / 操作 | 行为 | 费用 |
| --- | --- | --- |
| 调查员残缺手稿右键 | 观察研究，不结算 | 无 |
| 空手或灵界罗盘右键 | observe 观察应对，会结算 | 不消耗手持物 |
| 潜行空手右键 | avoid 回避 | 无 |
| 白蜡烛 / 灵性盐右键 | aid 帮助 | 此处只表示选择，不扣道具 |
| 绿宝石 / 金锭右键 | bargain 交易 | 此处只表示选择，不扣道具 |

这些规则延续旧版遭遇结算，不把“持有物”改成额外付费。稳定航路的 `/pm spirit stabilize` 仍使用旧版盐/蜡烛费用，与生态选择分开。

## 十二种生态的可读线索

以下生物造型、故事细节是基于本仓库与v0.9的同人改编，不把自创设定声明为原著正典。观察文字与Pages遭遇档案均来自同一份双语资源。

| 生物ID | 观察线索 |
| --- | --- |
| `lantern_moth_swarm` | 灯蛾围绕稳定的暗区飞舞；追逐光点会打乱队形。站定，观察它们留出的空隙。 |
| `memory_leech` | 水蛭模仿熟悉的声音；它每靠近一步，你对出发地的记忆就更模糊。保持距离，不回应。 |
| `prayer_echo` | 回响不是向你索取名字，而是围着快熄灭的烛光打转。留下一点温和的光。 |
| `spirit_ferryman` | 摆渡人守着空渡口，反复敲击桨柄；他伸出的手停在船票的位置。用约定的代价换路。 |
| `color_eater` | 它经过的地方会失去颜色；越明亮的光越容易被吞下。绕开灰白的边缘。 |
| `door_wisp` | 门灵不停穿过不存在的门框；每次回来，都朝同一个方向停顿。先读懂它的重复动作。 |
| `whisper_crow` | 呓语鸦只复述最后一个词，爪中却藏着亮片。它对交换比对命令更有兴趣。 |
| `compass_bird` | 鸟胸前的指针在颤动，羽毛上缠着灰雾。它认得方向，却需要稳定的光才能指路。 |
| `archive_spider` | 蛛丝上的书页按特定间隔翻动；触碰会毁掉顺序。观察留白，不要急着翻页。 |
| `gaslight_specter` | 灯影和火焰朝相反方向倾斜；那不是可供靠近的路灯。避开它投下的第二道影子。 |
| `theatre_maskling` | 面具灵在谢幕后仍伸手等候；它寻找的是有来有往的演出，而不是喝彩或追逐。 |
| `grave_lantern` | 墓灯摇曳却没有风；底座的盐圈已经断开。补上象征性的照护，而不是带走它。 |

每种遭遇都有独立成功与错误反馈，而不是只显示数值扣加。成功有轻柔结晶提示，失败有低沉确认音；使用原版声音事件及其字幕，不声称本轮制作了原创音频。危险仍通过文字、稳定度和漂移值表达，静音或降低粒子不会取消判定。

## 收集与持久化

- 手账分为“已观察”和“已成功应对”两个层级，每人12种；错误应对只能留下观察记录。
- 同一物种重复研究幂等，不生成物品、不增加奖励分、不改变稳定度、漂移、航路步数或截止时间。
- 记录按**世界 + 玩家UUID**保存在主世界 `lord_of_mysteries_spirit_field_journal` SavedData中；换维度、死亡、退出远征不会删除，重启可继续。
- 不占用普通知识集合，因此不会意外提高学徒知识链接概率或满足其他知识门。
- 非本人无法通过命令查看别人的手账；当前没有导出其他玩家记录的入口。
- schema1的12个物种位次由回归测试固定；未知高位被限制，畸形身份保留隔离，重复行合并，未来schema拒绝写入并原样保存。

## 修复的边界问题

1. **旧实体结算新遭遇**：航路现在持久记录唯一有效实体UUID。仅同物种或同所有者已不足以结算。
2. **跨维度坐标重合**：生态光环与右键必须确认实际维度一致、距离6格以内、本人、存活且非旁观者。
3. **到期竞态**：行为执行时直接检查期限、失败状态与独占活动策略，不再等待下一次每秒巡检才阻止操作。
4. **重复与孤儿实体**：失效实体周期清理；有效航路每4秒用UUID查询修复缺失实体，不每tick为每个玩家全图扫描。
5. **旧存档兼容**：缺少实体绑定的旧航路不会猜测授权；登录或巡检重建展示实体，航路分数与进度不变。Capability schema30和网络协议13不变。
6. **错误身份NBT**：生态种类以实际实体注册类型为准，不相信持久化文本伪装的另一物种。

## 展示与性能

- 已有生物模型增加可读的敌意举臂/挥击姿态；不改变攻击伤害或判定帧。
- 灵界生态不再继承僵尸环境呻吟；研究、成功/错误应对提供有语义的私有声音反馈。
- 在每tick 48/96/160新增预算之外，LOW/STANDARD/RICH增加350/1200/2200个寿命预约的总量预算。
- 预约在粒子预计寿命后释放，提前被引擎清理的粒子仍占预约到期，宁可少画而不是突破预算。降档不会立即删除已显示粒子，但会停止新增直到回落。
- 换世界、退出和时间回退重置预算；无闪屏、无相机震动，粒子不承担唯一的危险提示。
