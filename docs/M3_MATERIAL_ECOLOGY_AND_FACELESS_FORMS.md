# M3 专属材料生态与无面人形体记录

> 适用版本：`0.9.30-1.20.1`
>
> 数据基线：Capability schema 30 · content schema v4 · SimpleChannel protocol 13
> 状态：`playable candidate`；真实材料获取、保底恢复、形体记录、隐私迁移与世界运行已自动验证

## 1. 最短游玩路线

1. 输入 `/pm m3` 查看当前途径、序列、消化度和下一种专属材料。
2. 输入 `/pm items` 查看材料来源；输入 `/pm bestiary` 查看对应生物的威胁。
3. 优先狩猎材料生物；长时间找不到时使用本页的保底合成，不需要管理员发物品。
4. 按表中顺序向坩埚投入两个必要材料；第三槽加入辅材并把温度控制在理想值 ±5 可得到完美品质。
5. 序列 6 消化 100% 后输入 `/pm ritual`，完成对应序列 5 仪式证明，再服用序列 5 魔药。
6. 无面人使用潜行 `Y` 记录形体、普通 `Y` 切换伪装、潜行 `U` 轮换；命令入口为 `/pm faceless`。

## 5. 无面人形体记录

### 记录

- 条件：占卜家途径序列 6 或更高；对准 12 格内活着的非玩家生物。
- 操作：潜行按 `Y`，持续保持服务端视线 3 秒。
- 消耗：成功完成时扣 10 灵性；失去视线、目标死亡、超距或能力失效会取消且不扣费。
- 冷却：成功记录后 10 秒。
- 容量：最多 8 条；同类型、同名称和同摘要记录会规范化，损坏项会在加载时清洗。

### 使用

- 普通 `Y`：启用或解除当前所选身份。
- 启动消耗：25 灵性；持续消耗：每秒 2 灵性；冷却：60 秒。
- 潜行 `U`：切换到下一条记录；切换会安全解除当前伪装。
- `/pm faceless`：列出槽位、选中项和当前状态。
- `/pm faceless record|activate|cycle`：命令式记录、切换和轮换。
- `/pm faceless select <1..8>`：选择槽位。
- `/pm faceless clear <1..8>`：删除槽位。
- 死亡、退出服务器、失去对应序列、记录被删除或灵性耗尽都会解除伪装并恢复原自定义名称。

### 当前表现

当前实现提供服务端权威身份名、隐匿、移动轮廓和持续灵性成本，可用于潜入、撤离与角色扮演。它不会修改 Mojang 账号、权限、队伍、掉落归属或任何其他玩家的数据。精确皮肤、实体模型、动作和声线替换尚未实现，因此文档与 UI 不把它描述成完整视觉复制。

## 6. 隐私与反滥用

- 每条记录使用新的随机记录 UUID，与来源实体 UUID 无关。
- 持久数据只保存实体类型、显示名、是否玩家形态标志、宽高与最大生命摘要；不保存来源实体 UUID 或目标玩家 UUID。
- 策略层与服务层均拒绝所有玩家目标（包括自己和其他玩家）；当前玩家外观复制尚未开放。
- 每名玩家各自拥有记录列表、选中槽和两种冷却，两名玩家不会共享或覆盖。
- 显示名最多 48 个 Unicode 码点，实体 ID 必须是合法资源位置；非法、重复或超量记录沿用 schema 29 规则清洗，并由当前 schema 30 保持无法安全迁移的数据在孤儿区。
- 观众的情绪读取和表层读取会把正在伪装的无面人判定为“异常”，提供现有首批反伪装手段。
- 客户端只发送主/副能力意图；目标、视线、距离、灵性、冷却、记录和持续扣费全部由服务端重新计算。

## 7. 多人与重启

- 记录列表、选择槽、记录冷却和伪装冷却自 Capability schema 29 起持久化；schema 30 不改写这些字段。
- 伪装本身不会跨离线保持；退出服务器会主动恢复姓名并清理运行态，避免重登残留。
- Provider 往返保留规范化记录和选择，不保存正在凝视的临时目标。
- 真实 Forge GameTest 使用两个玩家验证列表隔离与玩家目标负向拒绝，使用真实村民完成形体记录，并检查序列化 NBT 不含村民或另一玩家 UUID。
- 材料生态 GameTest 会构造七种实体、加入真实服务器世界，并校验 Mod 注册 ID、存活状态、最大生命和攻击属性。

## 8. 故障排查

| 症状 | 检查 |
|---|---|
| `/pm m3` 没有给出 M3 目标 | 确认途径属于首发五途径且序列在 9–5；先完成 `/pm next` 指示的 M1 前置 |
| 记录立刻取消 | 保持准星、12 格距离和无遮挡视线满 3 秒；不要切换维度或让目标死亡 |
| 无法启用伪装 | 用 `/pm faceless` 检查是否有记录、选择是否合法、灵性是否至少 25、60 秒冷却是否结束 |
| 伪装很快解除 | 持续费用为 2 灵性/秒；补充灵性或主动关闭 |
| 找不到材料生物 | 用 `/pm bestiary` 核对维度；裂隙灵只在末地，其余七种当前都在主世界低权重生成 |
| 长时间没有掉落 | 掉落不是必定；使用抢夺附魔或保底合成，不需要管理员补发 |
| 坩埚产出错误 | 核对必要材料顺序、第三槽辅材与温度；旧代理材料不会再匹配序列 6–5 配方 |
| 旧存档形体记录异常 | 先备份，再执行 `/pm doctor`；当前 schema 30 会沿用形体规范化并保留不能安全解释的数据 |
