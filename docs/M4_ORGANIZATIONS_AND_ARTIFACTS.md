# M4 组织与封印物完整手册

> 适用版本：`0.9.33-1.20.1`
> 设计基线：v0.9；仓库现有行为与设计文档冲突时以已实现行为为准。
> 状态：M4 机器可玩范围完成；12 个组织、6 类行动、3 名轮值联络员、24/24 件封印物。
> 最后更新时间与时区以仓库根目录 `project-status.json` 为唯一来源。

## 1. 玩家最短路线

1. 到迷雾城前哨，输入 `/pm m4` 查看总览。
2. 与前哨三名轮值联络员交互，或输入 `/pm organization` 查看今日三项行动。
3. 输入 `/pm organization strategy` 查看 12 个组织本周的独立战略、风险与成败。
4. 与联络员交互直接接取，或输入 `/pm organization claim <1-3>`。
5. 完成服务端目标，回到前哨服务台 10 格内输入 `/pm organization submit`。
6. 首次完成组织行动会解锁“封印物保管”知识；对保管组织达到 8 声望后才可借用。
7. 输入 `/pm artifact catalog` 阅读已发现资料，再用 `/pm artifact borrow <编号>` 借用。
8. 使用 `/pm artifact` 查看自己的保管记录；泄漏时按事故档案备料并执行 `stabilize`，最后回库。

命令入口始终保留，因此联络员受阻、无障碍操作或服主排障时不会软锁。放弃行动使用
`/pm organization abandon`；同一玩家同时只能拥有一项组织行动。

## 2. 组织不是静态商店

七个教会与五个隐秘组织各有公开身份、隐秘单位、教义、资源、领地、盟敌关系与行动权重七个数据面。
服务器按世界种子、战略周和神秘暴露为每个组织独立选择周重点，再按世界种子与游戏日产生三项当日行动。

- 一个战略周为 7 个游戏日；`/pm organization strategy` 显示 12 项周指令。
- 当日三个组织不重复，行动有 1–5 级风险；暴露达到 40/70 会继续提高风险。
- 周战略有 70% 概率主导该组织当天行动，并抬高匹配行动的最低风险。
- 无玩家接取的行动会在跨日时由服务端确定性结算；普通停服或跳日逐日追赶。极端管理员跳时只重放“完整上周 + 当前周”这个可观察窗口，既精确恢复上周摘要和本周动量，也避免数百万天循环卡服。
- 玩家完成会记录该行动槽位的真实成功；多人完成同一公共槽位不会为战略统计重复刷成功。
- 跨周时保存上一周成功/失败摘要，旧存档缺少战略字段时会安全重建，不删除合法任务孤儿。

### 前哨轮值联络员

前哨保持三席实体联络员，对应今日三个行动。联络员会在三个时间段换位：

| 班次 | 世界时间 | 行为 |
|---|---:|---|
| 晨间会商 | 0–1999 | 靠近中央会商区，展示组织、行动、风险和本周重点 |
| 公开接洽 | 2000–11999 | 分散到三席服务位，交互可直接接取对应行动 |
| 夜间值守 | 12000–23999 | 回到夜间值守线，仍可接取和检查任务 |

联络员使用持久、无敌、无 AI 的村民载体；服务端每 100 tick 幂等维护，重复刷新不会复制实体。
日期、槽位、组织与行动写入实体持久数据，旧简报在交互时会拒绝，不会把昨天任务发给玩家。

## 3. 六类行动与原子结算

| 行动 | 完成方式 | 失败安全 |
|---|---|---|
| 夜间巡查 | 在前哨 64 格内击败 3 只怪物 | 只统计实际击杀者，不串到队友 |
| 封印物转运 | 把任意登记实例送回前哨 | 任务奖励替代直接归还奖励，不双发 |
| 异端材料复核 | 携带动态证据卷宗 | 不消耗卷宗 |
| 灾后救济 | 携带 8 个面包 | 仅全部校验通过后一次性消耗 |
| 高层议事 | 序列 5 或更高，且本组织声望至少 8 | 服务端读取真实 Capability |
| 秘密招募 | 本组织声望至少 4，并携带知识抄本 | 客户端不能自报完成 |

每项完成奖励为 `12 + 风险×12` 便士，并获得至少等于风险的组织声望。分配、进度、完成、消耗和奖励按玩家 UUID
隔离；多个玩家可参与同一公共行动，一人提交或放弃不会改变其他玩家状态。

## 4. 保管与知识发现

封印物使用主世界 `SavedData` 世界台账。每个实例记录：唯一 UUID、定义、保管组织、状态、责任人、持有人、
维度、坐标、污染、使用次数、借出/到期日、最后观察时间和事故数。

目录遵守发现链：

- 未完成过组织行动时，只能看到保管流程提示，不能借用；管理员可排障绕过知识显示门。
- 首次完成组织行动后解锁保管知识，目录才显示每件封印物的效果、代价与事故材料。
- 借用、观察或合法使用某件封印物会解锁该件的具体知识条目。
- 知识只控制说明与借用前置，不替代真实声望、台账状态或权限判断。

## 7. 状态机与负向路径

| 状态 | 含义 | 可执行操作 |
|---|---|---|
| `borrowed` | 责任人正常借用 | 合法使用、丢落追踪、正常归还 |
| `leaked` | 逾期、超安全次数或污染过阈值 | 仅稳定；不能使用或直接归还 |
| `recovered` | 非责任人找回，或泄漏已稳定 | 保持封印，只允许回库 |
| `returned` | 已回库并释放唯一库位 | 世界旧副本继续无效 |
| `abused` | 同 UUID 复制、同 tick 双持或严重冲突 | 全部隔离，仅管理员审计/退役 |

- 同定义世界同时只能有一个活跃实例；竞争借用无损拒绝。
- 责任人离线、物品掉落或无人加载都不会暂停到期日；主世界台账仍会转入泄漏。
- 正常换手进入 `recovered`，责任 UUID 不转嫁给拾取者。
- 同玩家背包复制和跨玩家同 tick 双持均转入 `abused`；伪造绑定或类型不匹配直接隔离。
- 普通 `/pm artifact` 只显示本人负责或持有的记录，且能安全处理 `holder=null` 的遗失/已归还记录。
- `/pm artifact admin ledger` 与 `retire <UUID>` 仅权限 2；退役释放库位，不把世界复制物洗成合法物。

## 8. 单人、多人和重启保证

- 单人无需另一名玩家：千面之镜有自身回声回退，所有组织目标都有单人完成路径。
- 多人共享世界行动，但任务分配、击杀进度、材料、奖励和完成记录完全隔离。
- 同一行动槽只计一次组织战略成功，避免多人重复结算扭曲周报。
- 跨日跳跃结算无人行动；跨度超过两周时有界重放完整上周与当前周，时钟回拨会重建目标日战略，不把未来行动误计入过去。
- 任务、周战略、保管实例与事故都保存于主世界 SavedData，重启后恢复。
- 来客面具不影响旅行家组织门、领地、管理员或任何其他权限。
- 白噪音烛台只改变灵视/简易占卜的目标可见性，不篡改实体权限和数据。

排障顺序：先 `/pm doctor` 与 `/pm servercheck`，再检查玩家是否在主世界前哨、是否已发现保管知识、保管组织真实声望是否至少 8、
实例状态与材料是否匹配。不要通过复制 NBT 或直接清理台账“修复”；需要解除 `abused` 库位时只使用管理员退役命令并保留备份。
