# M4 组织与封印物：首批可玩手册

> 适用版本：`0.9.31-1.20.1`  
> 设计基线：v0.9  
> 状态：M4 `active`，首批可玩闭环；当前实现 12 个组织、6 类自主行动、7/24 件封印物。  
> 最后更新时间与时区以仓库根目录 `project-status.json` 为唯一来源。

## 1. 这批内容真正实现了什么

M4 不再把“组织”当作只在文本里出现的声望名称。服务器每天会根据世界种子、游戏日和当前最高神秘暴露，为 12 个组织确定三项行动。即使没有玩家接取，行动仍会按天刷新；玩家只能参与，不能决定组织是否行动。

每个组织都有七个数据面：

1. 公开身份；
2. 隐秘单位；
3. 教义；
4. 资源；
5. 领地；
6. 盟友与敌对关系；
7. 自主行动策略权重。

首批封印物使用主世界 `SavedData` 保管台账。每一件借出实例都记录：

- 唯一实例 UUID；
- 封印物与保管组织；
- 责任人和当前持有人；
- 最后维度与坐标；
- 污染、使用次数与事故；
- 借出日、到期日和最后观察时间；
- `borrowed / leaked / recovered / returned / abused` 状态。

## 2. 新玩家从哪里开始

1. 输入 `/pm m4` 查看当前边界、组织目录和今日行动。
2. 输入 `/pm organization` 查看三项行动。
3. 输入 `/pm organization claim <1-3>` 接取一项。
4. 按提示完成目标，回到迷雾城前哨服务台 10 格内。
5. 输入 `/pm organization submit` 结算声望和便士。
6. 对某个封印物的保管组织达到 8 点声望后，在服务台输入 `/pm artifact borrow <编号>`。
7. 使用 `/pm artifact` 查看台账；完成后在服务台输入 `/pm artifact return`。

放弃任务使用 `/pm organization abandon`。同一玩家同时只能拥有一项组织任务，但不同玩家可以独立接取同一项公共行动，进度和奖励互不覆盖。

## 3. 六类组织行动

| 行动 | 服务端目标 | 关键约束 |
|---|---|---|
| 夜间巡查 | 在前哨 64 格内击败 3 只怪物 | 只统计击杀者自己的已接任务 |
| 封印物转运 | 把任意登记封印物带回服务台 | 任务奖励替代直接归还奖励，不重复结算 |
| 异端材料复核 | 携带动态证据卷宗提交 | 不消耗卷宗 |
| 灾后救济 | 携带 8 个面包提交 | 只在全部校验通过后消耗 |
| 高层议事 | 序列 5 或更高，且该组织声望至少 8 | 服务端读取真实 Capability |
| 秘密招募 | 该组织声望至少 4，并携带知识抄本 | 不能伪造客户端完成状态 |

每日行动的三个组织不会重复。神秘暴露达到 40 和 70 时风险分别再提高一级，最高为 5；风险会提高组织声望与便士奖励。

使用 `/pm artifact catalog` 查看安全次数、借期、泄漏阈值、效果与代价。借用编号可以写短 ID，例如：

```text
/pm artifact borrow artifact_3_091_kindly_umbrella
```

来客面具使用：

```text

```

面具只写入可见伪装元数据并施加短暂隐身。旅行家组织门和其他权限系统仍从服务器 Capability 实时读取真实组织声望。

## 5. 泄漏、遗失、换手和复制

### 安全使用与污染

每次成功使用后，台账同时增加使用次数和污染。超过 `safe_uses`，或污染达到 `leak_threshold`，实例进入 `leaked` 并自动封印。

### 离线和遗失

服务器每 100 tick 检查一次借期。即使责任人离线、物品掉落或没有玩家观察，到期后也会进入泄漏状态。持有人再次上线或拾取时，封印和后果会在服务端恢复。

### 换手

非责任人持有一个正常借出实例时，台账进入 `recovered`。回收者不能擅自使用，但可以把它送回前哨。

### 复制

- 同一玩家背包出现两个相同实例 UUID：台账进入 `abused`，副本全部隔离；
- 同一服务器 tick 出现两个不同持有人：台账进入 `abused`；
- 物品类型、定义 ID 或实例记录不匹配：伪造物隔离；
- 未登记的新封印物不可使用；旧版永燃火柴盒仅在没有活跃实例时允许一次迁移登记。

隔离实例不会自行解锁。管理员确认后可执行：

```text
/pm artifact admin ledger
/pm artifact admin retire <实例UUID>
```

退役只把台账库位释放为可重新借出；世界中的原复制物仍保持隔离。

## 6. 泄漏恢复

持有 `leaked` 实例时准备：

- 安神香 ×1；
- 纯水 ×1。

输入 `/pm artifact stabilize`。成功后实例进入 `recovered`，继续保持封印，必须送回前哨并使用 `/pm artifact return`。材料只在台账状态、持有人和数量全部校验通过后消耗。

## 7. 单人与多人保证

- 组织行动列表是世界级，但任务分配、进度、完成记录和奖励按玩家 UUID 隔离；
- 一个玩家不能覆盖自己的已有任务，多个玩家可以并行参与同一行动；
- 击杀进度只记到实际击杀者；
- 封印物是世界级唯一实例，不按队伍复制；
- 换队、死亡、重连、维度切换和服务器保存不会改变责任 UUID；
- 来客面具不影响权限；
- 灾后救济在失败路径不消耗面包；
- 封印物转运不同时发放直接归还奖励和任务奖励。
