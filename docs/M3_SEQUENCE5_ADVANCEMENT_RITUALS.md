# M3 序列 5 专属晋升仪式

> 适用版本：0.9.26-1.20.1
> 设计来源：Project Mystery v0.9 第 7.3–7.7、5.5、12.3 节
> 实现状态：五途径仪式纵切 `code_ready`；真人长期平衡仍待验收

## 1. 为什么序列 5 不再只喝魔药

序列 6 消化度达到 100% 后，玩家仍可炼制对应序列 5 魔药，但服务端会拒绝直接服用。晋升者必须先完成本途径的专属仪式，仪式证明写入玩家 `knownKnowledge`，因此：

- 证明绑定玩家和途径，队友不能替代晋升者完成。
- 完成后可跨死亡、重登和服务器重启保留。
- 仅拿到魔药、复制客户端数据或换人服用不能绕过门禁。
- 已经在旧版本晋升到序列 5 的玩家不会被降级或破坏存档。

游戏内输入 `/pm ritual` 可随时查看当前途径、序列、消化度、仪式状态和准备要求。

## 2. 通用祭坛

所有五种仪式复用现有可制作的仪式祭坛与粉笔阵纹：

1. 放置 `ritual_altar`。
2. 以祭坛为中心，在 `(±3, 0)`、`(0, ±3)` 和 `(±2, ±2)` 八个位置放置 `ritual_chalk_mark`。
3. 抵达本途径序列 6，并把消化度提升至 100%。
4. 炼制并手持对应序列 5 魔药。
5. 普通右键祭坛执行无损检查；服务器会显示缺失条件、协助者数量和稳定度。
6. 条件齐全后潜行右键正式执行。此时才消耗材料并进行结算。
7. 成功后服用魔药，进入序列 5。

检查阶段不会扣材料、灵性、压力或污染。正式执行后无论成功与否都会消耗仪式材料，避免退出重进或多人重复交互复制结算。

## 3. 五途径准备矩阵

| 途径 / 序列 5 | 仪式 | 环境 | 消耗材料 | 不消耗的准备物 | 多人协助焦点 |
|---|---|---|---|---|---|
| 占卜家 / 秘偶大师 | 提线仪式 | 夜晚、祭坛上方可见天空 | 白蜡烛×5、线×1 | — | 潜行手持线 |
| 观众 / 梦境行者 | 入梦仪式 | 祭坛四格内有床 | 白蜡烛×2、梦鳞碎片×1 | 床 | 潜行手持羽毛 |
| 猎人 / 收割者 | 战火仪式 | 祭坛四格内有点燃的营火或灵魂营火 | 骨头×5、烬火蝾螈腺体×1 | 营火 | 潜行手持盾牌 |
| 偷盗者 / 窃梦家 | 窃梦仪式 | 六格内有沉睡生物；或夜晚四格内有床 | 梦鳞碎片×1、紫水晶碎片×1 | 沉睡者或床 | 潜行手持紫水晶碎片 |
| 学徒 / 旅行家 | 启门仪式 | 背包中至少两个绑定不同磁石坐标的罗盘 | 星光苔藓×2、镜蟹壳×1 | 两个磁石罗盘 | 潜行手持罗盘 |

旅行家的罗盘不会消耗。服务器同时比较维度和坐标；两个指向同一磁石的罗盘只算一个空间标记。

## 4. 单人与多人

五种仪式都可以单人完成，不会因服务器人数不足形成永久软锁。低污染、低压力的单人准备具有 90% 基础稳定度，并直接进入稳定成功档。

多人协助是可选的风险管理和团队分工：

- 协助者必须在祭坛七格内。
- 协助者必须主动潜行并手持该途径的协助焦点，避免路过玩家被动卷入。
- 最多记录三名协助者，每人增加 8% 稳定度。
- 协助者不消耗手中焦点，也不会获得晋升证明。
- 成功后主持者和协助者都会收到服务端反馈。
- 不同队伍玩家可以自愿协助，但无法修改主持者途径、材料或结算结果。

## 5. 稳定度与世界事件

服务端使用下式计算正式执行时的稳定度：

```text
稳定度 =
  0.90
  - 污染 × 0.004
  - 失控压力 × 0.0025
  + min(协助者, 3) × 0.08
  + 仪式共鸣事件加成
```

结果钳制在 `0.10–1.00`。雾都世界事件“仪式共鸣”增加 `0.10`，其他事件不额外提高晋升仪式。

- 稳定度不低于 85%：确定性稳定成功，不进行随机失败。
- 稳定度低于 85%：按服务器随机源进入勉强成功、普通失败或严重失败。
- 创造模式可以免除消耗材料，但仍需满足途径、序列、消化、阵纹和环境要求，避免管理员误测试错误布局。

## 6. 结算和失败恢复

| 结果 | 晋升证明 | 后果 |
|---|---|---|
| 稳定成功 | 写入 | 无额外风险，授予“门槛不再只是魔药”成就 |
| 勉强成功 | 写入 | 失控压力 +5、污染 +2 |
| 普通失败 | 不写入 | 失控压力 +12、污染 +6 |
| 严重失败 | 不写入 | 失控压力 +20、污染 +15，并生成针对主持者的失控灵体 |

失败后建议：

1. 先离开祭坛处理敌对灵体。
2. 使用睡眠、镇静熏香、心理服务或净化手段降低压力与污染。
3. 输入 `/pm ritual` 再次核对状态。
4. 补充材料；需要时邀请协助者提高稳定度。
5. 不要在污染或压力接近 100 时连续重试。

失败不会消耗序列 5 魔药，也不会改变当前途径、序列、消化度或已有特性账本。

## 7. 服务端与存档边界

- 晋升证明通过玩家 Capability 的既有知识集合保存，不新增不透明客户端状态。
- `PotionAdvancementRules` 同时检查同途径、前一序列、100% 消化和仪式证明。
- `use` 和 `finishUsingItem` 都重复验证，开始饮用后换物品或状态变化不能绕过。
- 五条途径使用不同证明 ID，错误途径证明不互通。
- 五途径链式 GameTest 先确认无证明时序列保持 6，再写入正确证明并晋升到 5，最后执行 Provider 序列化往返。
- 独立真实世界 GameTest 搭建祭坛、八点粉笔阵和观众床铺环境，使用生存背包材料验证普通右键不消耗、潜行确认精确消耗，以及仪式证明可重启持久化。
- 材料检查与扣除均在服务端主线程执行；客户端不能自报材料、稳定度、协助者或结果。

## 8. 真人验收清单

每条途径至少记录一次单人和一次多人执行：

| 场景 | 必测结果 |
|---|---|
| 错误途径魔药 | 拒绝，不消耗 |
| 序列不是 6 | 拒绝，不消耗 |
| 消化低于 100% | 拒绝，不消耗 |
| 阵纹缺一处 | 拒绝，不消耗 |
| 环境或材料缺失 | 显示该途径详细要求 |
| 普通右键 | 只检查，不消耗 |
| 潜行右键 | 正式结算，只执行一次 |
| 单人低风险 | 稳定成功 |
| 三人协助 | 协助者计数不超过三，焦点不消耗 |
| 失败 | 魔药保留，材料消耗，风险增加 |
| 严重失败 | 生成失控灵体且目标为主持者 |
| 重登与重启 | 仪式证明仍在，序列 5 魔药可服用 |
| 错误证明 ID | 不解锁其他途径 |

## 9. 当前事实边界

本批实现的是五条途径序列 5 的专属晋升门禁、物理环境、材料、风险和多人准备纵切。它不代表以下完整子系统已经完成：

- 秘偶大师的永久秘偶、收纳和跨区块控制。
- 梦境行者与窃梦家的共享梦境维度和玩家同意式入梦。
- 收割者的完整战争领域和长期战团经济。
- 旅行家的磁石持久标记、20 秒命名双向门、私人/队伍/公开权限、持久黑名单和领地兼容基础已完成；具体领地 Mod 适配器、组织权限和管理员工具仍待实现。
- 五途径专属生物生态、最终材料、美术、音效和真人长期平衡。

这些项目继续保留在 M3 Issue 与路线图中，不会因仪式门禁上线而被误报为完成。
