Start Here

按你的目标进入

不需要先读完整设计文档。选择一个入口，几分钟内进入对应流程。

01

新玩家

第一次进入世界

安装 Forge 1.20.1 与 Mod，进入世界后输入 /pm next，跟随罗盘抵达调查员营地。

打开完整入门指南 ↗
02

M2 玩家

调查与城市生活

通过调查板管理案件、证据、假说与复议；使用 /pm city 和 /pm life 进入工作与城市事件。

阅读调查手册 ↗
03

M3 玩家

材料生态、形体、组织远门与秘偶

先用 /pm m3 获取下一步，用 /pm m3 team 查看近距离同队职责缺口；/pm items 与 /pm bestiary 指向专属材料和生物。无面人用 /pm faceless 管理八槽形体，旅行家用 /pm travel 管理四档权限、组织门和端点运维，秘偶大师用 /pm marionette 管理三槽持久秘偶编队、三种战术、离线休眠、秘偶收纳卷轴与跨维安全部署。

打开 M3 玩家入口 ↗
04

M4 玩家

组织行动与封印物保管

用 /pm m4 查看每日行动，与三席轮值联络员交互，查询12组织周战略；完成行动解锁保管知识后，可借用24件封印物并处理六类事故。

打开 M4 玩家手册 ↗
05

M5 玩家

灵界实体生态与共享梦境

以航路灯进入五类投影，和12类实体生态交互；或由2–4名同队、同组织信任玩家明确接受邀请，在独立梦境中完成四轮符号投票与逐人安全结算。

打开 M5 灵界远征手册 ↗ 打开共享梦境手册 ↗
06

恢复与排障

梦境、灵界、远门或仪式被拒绝

先输入 /pm activity 查看服务端权威状态，再按提示安全退出或恢复。原子门禁会保留材料、灵性、冷却、位置与账本。

打开跨系统安全手册 ↗
07

服主 / 开发者

部署、诊断与贡献

用 /pm doctor 与 /pm servercheck 检查专服；开发前先阅读设计基线与贡献门禁。

六个步骤形成完整循环；每一步都影响下一次晋升的收益与风险。

    Progress

    现在真正做到哪里

    严格区分可玩、代码就绪与需要真人验证的内容，不用测试数量替代实际体验。

    M2 机器范围完成

    调查与生活

    正式街区、动态案件、证据推理、组织响应、职业经济、神秘暴露与世界事件已经形成服务端权威闭环。

    • 单人 / 多人状态隔离与恢复路径已覆盖
    • 保留四人连续八小时与经济平衡真人门禁
    M3 机器范围完成

    五条首发途径

    序列 6–5 已具备 10 瓶魔药、10 种最终材料、7 种生态生物、20 项能力、20 项扮演、五种专属仪式、无面人八槽形体、旅行家四档双向远门/组织实时准入/端点运维、秘偶大师三槽持久秘偶编队/三种战术/离线休眠/权威收纳/跨维安全部署、队伍职责顾问、非凡特性加工及全服来源审计。

    特性分离台与洗涤台提供守恒拆分、同途径重组、封存和有纯度代价的净化；主世界账本阻止已消费来源跨玩家、跨维度或重启后重放。

    • 来源重放不扣特性、催化剂、探针耐久或析出材料，处理结果由服务端原子结算
    • 精确玩家皮肤/模型/声线、复杂秘偶阵型、高精美术和真人互补长测仍是 M3 发布边界；具体领地 Mod 适配归入 M7
    M4 机器范围完成

    组织与封印物

    七个教会、五个隐秘组织、六类行动、12项独立周战略、跨日无人结算、三席轮值联络员和24件封印物已形成服务端权威闭环。世界台账覆盖唯一借出、知识门、责任人/持有人、离线逾期、污染与安全次数、六类事故、换手回收、复制隔离、稳定、归还和管理员退役。

    • Pages图鉴直接从12份组织定义、24份封印物定义、Forge注册表和双语资源生成
    • M4机器合同已关闭；高精美术、更多专属建筑与真人多人长测继续作为发布质量工作
    M5 机器范围完成

    灵界与梦境

    30分钟灵界远征、12类真实生态实体和2–4人共享梦境已形成服务端权威闭环；共享梦境包含四类语义场景、八种符号、四轮全员投票、组织奖励与逐人恢复。

    • 远征实体绑定所有者；梦境要求逐人明确同意，全员接受前不传送、不扣材料
    • 断线、错维、死亡、退队、权限变化、重启和坏档均有失败关闭或恢复路径
    • 梦境、灵界、远门、仪式与秘偶使用七态服务端门禁互斥；/pm activity 提供无副作用恢复指引
    M6 当前里程碑
