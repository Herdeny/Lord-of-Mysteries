## 从普通人开始

1. 做研钵：5石砖+1紫水晶碎片。输入 `/pm survival recipes` 看当前数据包的真实配方。
2. 获取夜枭视络：暗森林、针叶林、原始松木针叶林的黑暗处寻找夜枭；或尝试新手牧师交易池（8绿宝石/份，最多3次，原版补货）。交易池候选不保证每名村民都有；可探索或更换未锁定交易的村民。已有锁定交易不会被重写。
3. 咖啡豆：农民新手交易池（1绿宝石/4豆，最多8次），或营火烘烤可可豆30秒。后者是MC生存替代路线，不是现实咖啡种植或原著设定。
4. 工作台：2咖啡豆+糖+水桶+玻璃瓶，得到浓黑咖啡；水桶返还空桶。
5. 暗影蘑菇：牧师新手交易池（1绿宝石/2菇，最多8次）；或研钵主手棕色蘑菇、副手黑蜡，各1份。失控体不眠残影也掉落，但不推荐靠故意失控获取。
6. 研钵主手浓黑咖啡、副手暗影蘑菇，各1份 → 守夜辅料1份，并返还玻璃瓶。不是喝咖啡；普通人也能加工。
7. 坩埚依次投入 **夜枭视络 → 守夜辅料 → 灰烬粉末**。前两项必须有，灰烬粉末可提高品质。沿用坩埚温度/顺序和品质规则，理想70°C，营火可达；炼制60秒。
8. 只有未选择途径的普通人能喝不眠者魔药。成功获得114灵性上限、特性账本、身份卡与反思日记。另一条途径不能靠喝药免费转途径。
9. 输入 `/pm next` 或 `/pm nightwatch`，按 **Y** 切换夜视，**U** 查看守夜状态。按键可在原版控制设置重新绑定。

## 能力、代价与边界

| 能力 | 真实行为 | 约束 |
|---|---|---|
| 夜视 | 原版夜视效果；每秒0.5灵性 | 无灵性自动关闭，不覆盖更强/更长的外部夜视 |
| 黑暗感知反馈 | 自己可见的敌对头部暗影粒子 | 12格、视线可达、非隐身、最多12只；不是透墙轮廓或全队共享雷达 |
| 惊醒 | 睡眠中遭生物攻击立即起身，阻止首击并给1秒保护 | 10秒触发冷却；虚空等绕过无敌的伤害不拦截；不回满生命/饥饿/灵性 |
| 静夜潜行 | 主世界夜间脚步音量降至30% | 不静音攻击/受伤提示；多人声源重叠无法唯一归属时保留原音 |
| 守夜层数 | 连续完整夜晚+1，最多5 | 主世界时间13000–23000，游戏时间连续；中途加入不算 |
| 夜间收益 | 每层移速+4%、攻击+6% | 没有无限堆叠，没有加减最大生命造成的回血循环 |
| 白昼倦怠 | 每层移速-10%，最多-50% | 不永久降低基础属性；切途径/离开合法状态移除专属修饰器 |
| 夜间灵性恢复 | 满足既有安全恢复条件后乘1.4 | 仍要求非近期战斗、亮度≥7、低压力和无独占活动；不是无条件回能 |

`/pm nightwatch vision` 与Y等价；`/pm nightwatch status` 查看层数、本夜已观察秒数、有效袭击数量与夜视状态。

## 怎样完成扮演

- 从入夜开始持续在主世界清醒，到黎明前结束观察；必须是真实游戏tick推进，`/time set`、时间回退、跳过夜晚不会补发。
- 整夜内击败至少3只**攻击目标为你、存在至少200tick的敌对生物**，才触发 `sleepless9_all_night`。单只UUID重复回调最多记一次；不杀玩家、被动动物或新生成瞬间的刷怪蛋来凑数。
- 基础消化+12，最终数值沿用仓库品质/压力/新颖度/负载/服务器倍率。平安整夜仍加守夜层，但不获得这项战斗扮演收益。
- 睡眠请求、死亡、退出、跨维度、灵界/共享梦境等独占活动会中断本夜；已完成层数保留。离线/重启期间不累计，重启后下一个完整夜晚可继续。
- 数值到100%也不会凭空出现序列8魔药；午夜诗人及后续7–5仍待实现。

## 恢复与物品安全

白昼已有倦怠时喝浓黑咖啡32tick，清除**当日**白昼惩罚，保留层数。次日惩罚恢复。没有倦怠、正在独占活动、旁观者或死亡时不扣咖啡；喝到结束时再次检查。生存返还玻璃瓶；满包掉落在本人脚下；创造不消耗。

教会晨祷尚未接入，不能把普通祭坛当作已实现晨祷。保持咖啡储备即可完成本轮闭环。失败配方沿用污染混合物规则，先用低风险环境试炼，不要把高污染当成更好品质。

## 多人、持久化与旧档

- 服务端权威；无新C2S包。沿用协议13、玩家schema30，新增独立 `lord_of_mysteries_nightwatch.dat` schema1。
- 每玩家UUID独立的层数、当日咖啡、已结算夜晚、惊醒冷却。未完成夜晚不存档续算，防离线补发和重启重复奖励。
- 未知未来schema或错误列表类型保留原NBT、只读拒绝；重复/缺失UUID记录隔离保存。
- 夜视开关和本轮临时动画不写进跨服账号；退出/维度切换清理，避免效果粘连。外部夜视匹配不到自有特征时不删除。
- 夜枭正常按怪物生成规则出现；不会重建旧区块，也不替换原版地形。和平模式可用交易/加工获得材料；战斗扮演在和平模式不计。
- 不眠残影使用独立兜帽模型与既有特性掉落链，不在水中转成原版溺尸而丢失特性。
