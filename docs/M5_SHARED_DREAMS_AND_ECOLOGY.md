# M5 共享梦境与实体生态手册

> 适用版本：`0.9.35-1.20.1` · 机器可玩范围完成 · 设计基线：v0.9

## 玩法目标

共享梦境是 2–4 名同队、同组织信任玩家共同解释线索的服务端玩法，不是把主世界区块完整复制到梦里。服务器在独立的 `lord_of_mysteries:shared_dream` 维度建立语义场景，保存每名参与者的现实锚点、明确同意、投票、场景进度、连贯度、创伤和线索分数。

四类场景为“缺席的客人”“循环剧院”“沉没档案馆”“褪色街道”；每局从八种符号中确定四轮线索。每名参与者每轮只能投一次 `interpret`、`anchor`、`comfort` 或 `confront`，全员投票后以多数决结算，平票由主持人的选择打破。

## 准备与进入

主持人与所有受邀者必须：

- 在线、存活、非旁观者，处于同一维度且相距不超过 24 格。
- 队伍状态一致；无队伍时只能与同样无队伍的玩家建立梦境。
- 对同一组织拥有至少 4 点声望，且没有进行中的灵界远征或其他梦境。
- 主持人携带入梦缎带、见证石，以及梦境锚钟或可正常使用的绑定“沉睡之铃”。

```text
/pm dream
/pm dream invite <player> <organization>
/pm dream accept
/pm dream decline
/pm dream start
/pm dream status
/pm dream act <interpret|anchor|comfort|confront>
/pm dream leave
/pm dream recover
/pm activity
```

邀请有效期为 60 秒。每名玩家必须自行执行 `accept`；在所有人接受并再次通过距离、队伍、维度、组织权限和冲突检查前，服务器不会传送任何人，也不会消耗仪式物品。主持人可在同一大厅继续邀请，参与人数上限为 4。

## 四轮符号协作

- 初始连贯度 80，范围 0–100；创伤范围 0–100。
- 正确解释按参与人数增加连贯度和线索，降低创伤；错误解释降低连贯度并提高创伤。
- 四轮完成后，每名参与者分别获得梦境记忆、记忆碎片、组织声望、共享梦境知识和本局知识记录。
- 若玩家当前负责同组织的异端复核或高层议事行动，线索分数会推进该任务。
- 失败、主动离开或安全门禁触发时发放梦境创伤碎片并增加精神压力；记忆贤者可可可缩短精神创伤并降低压力。
- 梦境记忆可回流占卜水晶；创伤碎片、安神香与可可可转化为记忆碎片，避免恢复软锁。

## 同意与失败关闭

以下规则由服务器逐秒检查，任一失败会关闭整场梦境并为每位参与者建立独立恢复记录：

| 条件 | 行为 |
|---|---|
| 玩家拒绝或邀请超时 | 关闭大厅，不传送、不扣材料 |
| 重复邀请、超过四人或玩家已在其他会话 | 无损拒绝 |
| 断线 | 关闭会话；离线玩家的返航和结算排队到下次登录 |
| 离开梦境维度 | 以错误维度关闭，不允许在现实继续投票 |
| 梦中死亡 | 取消真实死亡，恢复最低生命并转为梦境创伤 |
| 队伍变更或解散 | 以队伍变化关闭，防止旧同意被复用 |
| 组织声望降到门槛以下 | 以权限丢失关闭，封印物或伪装不能绕过 |
| 10 分钟会话超时 | 安全返航并结算创伤，不永久困住玩家 |

梦境大厅、活动会话、待恢复记录或孤立梦境维度都属于服务端权威独占活动。此时灵界进入、旅行家开门/穿门、序列5晋升仪式、净化仪式和秘偶收纳/部署会在扣费、冷却、传送、生成实体或改写账本之前拒绝。执行 `/pm activity` 可区分当前阶段并取得 `/pm dream leave|exit|recover` 等恢复指引。

## 存档、重启与防复制

- `lord_of_mysteries_shared_dreams` SavedData 使用 schema 1，保存大厅、参与者、同意、现实锚点、投票与待恢复记录。
- 会话和玩家映射按整体载入；重复玩家、非法 UUID、错误状态或部分冲突进入孤儿区，不留下半条合法会话。
- 未来 schema 在旧版本中只读原样保全，禁止降级覆盖。
- 每个玩家同一时刻只允许一条恢复记录；结算先删除恢复凭证再发奖励，优先阻止崩溃重放复制。
- 返回前验证维度、世界边界和世界边框，再加载区块并寻找安全落点；原锚点失效时退回主世界出生点。
- 正常重连会恢复活动梦境；崩溃重启提供登录宽限。明确退出事件则立即失败关闭，不以宽限掩盖断线。

## 十二类实体生态

灵界远征的十二类档案现在都有 Forge 实体注册、双语名称和生成蛋。航路实体绑定远征所有者、对应遭遇和投影平台；只有所有者右键可结算，其他玩家不能抢答或替换结果。服务端在遭遇解决、返航或异常关闭后清理实体，并在重连时补建缺失实体、清理错误种类或过远的旧实体。

现阶段实体共享稳定的基础渲染器，但具有差异化名称、粒子、附近环境效果、首选应对、风险和奖励。该降级资源不影响专服规则；专属模型、动画与声音属于发布资产增强，不影响 M5 状态机完成度。

## 自动化验收

- `SharedDreamPolicyTest`：场景/符号确定性、正确/错误行为、边界钳制、十二实体映射。
- `SharedDreamSavedDataTest`：明确同意、全员投票、NBT 往返、离线恢复、防重复、坏档原子隔离、未来 schema 只读。
- 两项新增 Forge GameTest：共享梦境维度与十二实体真实构造；2–4人同意、四轮投票、奖励证据与恢复记录重启持久化。
- M5 合同、资源完整性、Pages 自动图鉴、存档回滚、专服双启动和 `clean build` 共同门禁。
- `OccultActivityPolicyTest` 全枚举普通、大厅、活动、待恢复、孤立梦境维度、灵界和双记录冲突；第29项Forge GameTest在真实服务器中验证跨系统拒绝不扣材料、灵性、耐久，不传送、不生成门或秘偶，也不写入账本。

自动化证明状态转换与恢复路径存在，不替代真人 30 分钟多人延迟、资源产销、可读性和手感平衡记录。
