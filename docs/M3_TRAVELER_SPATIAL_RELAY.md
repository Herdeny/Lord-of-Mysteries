# M3 旅行家空间标记与同行远门

> 适用版本：0.9.24-1.20.1
> 实现状态：`code_ready`
> 设计原则：服务端权威、明确同意、失败不扣费、原版存档兼容

## 1. 玩家目标

旅行家序列 5 现在可以把原版磁石指南针作为持久空间标记。指南针自身保存维度和方块坐标，因此不增加新的玩家存档字段，也不会破坏现有 Capability schema 24。

最短操作路线：

1. 在目标位置放置原版磁石。
2. 手持原版指南针对磁石右键，使指南针绑定该磁石。
3. 输入 `/pm travel` 检查维度、坐标和磁石是否仍有效。
4. 旅行家手持该指南针按 `U` 开启远门。
5. 同行者必须在旅行家四格内、主动潜行，并手持指向同一磁石的指南针。

如果旅行家双手都没有指南针，`U` 保留原有“返回雾都前哨”兼容行为；只要任一只手拿着指南针，就会严格走空间标记校验，失效或未绑定的指南针不会退回前哨逻辑，也不会扣灵性。

## 2. 消耗与冷却

| 项目 | 数值 |
|---|---:|
| 主持旅行家基础消耗 | 80 灵性 |
| 每名同行者额外消耗 | 10 灵性 |
| 同行人数上限 | 3 人 |
| 主持者冷却 | 36,000 tick / 30 分钟 |
| 同行者再次搭乘冷却 | 1,200 tick / 60 秒 |
| 同意半径 | 4 格 |
| 抵达保护 | 抗性提升 III，5 秒 |

总消耗在 80–110 灵性之间。系统先完成维度、磁石、世界边界、碰撞和全员落脚位预检，再扣除灵性；预检失败不会改变冷却、位置或物品。

## 3. 明确同意规则

同行者必须同时满足：

- 与主持者位于同一来源维度；
- 存活，且不是旁观者或睡眠状态；
- 距离主持者不超过四格；
- 正在潜行；
- 手持指向完全相同维度和坐标的磁石指南针；
- 没有处于 60 秒搭乘冷却。

候选人按 UUID 确定性排序后最多选择三人。没有潜行、拿错指南针、距离过远或处于冷却的玩家会留在原地，不能被主持者强制拉走。

## 4. 目标安全校验

服务器只接受当前已加载服务器中的合法维度，并按以下顺序校验：

1. 目标坐标必须位于维度高度范围和世界边界内。
2. 通过边界检查后才允许加载目标区块，恶意超大坐标不能触发越界区块加载。
3. 指南针记录位置必须仍是原版磁石。
4. 为主持者和每名同行者分别搜索独立落脚位。
5. 每个落脚位下方必须有坚实上表面，玩家碰撞箱不得与方块冲突。
6. 全员落脚位全部找到后才扣费并执行传送。

跨维度传送由服务器执行。若执行过程中任一成员转移失败，系统尝试把已经移动的成员送回各自原位置，并返还主持者本次消耗。

## 5. 单人、多人和服务器行为

- 单人可直接使用，费用固定为 80 灵性。
- 多人不依赖客户端上报玩家列表；服务器从主持者所在维度的真实在线玩家中筛选。
- 指南针、磁石和所有乘客状态均由服务端读取。
- 远门不会消耗指南针或磁石。
- 成功后主持者和同行者获得短暂抵抗，减少目标区块尚未完全可见时的意外伤害。
- 冷却使用现有持久数据：主持者沿用旅行家副能力字段；乘客冷却写入服务端持久实体数据。
- 当前实现是“一次性远门转移”，不是持续存在、可往返的门实体。

## 6. 失败与恢复

| 失败原因 | 结果 |
|---|---|
| 指南针未绑定 | 提示重新绑定；不扣费、不冷却 |
| 目标维度不可用 | 拒绝执行；不加载未知维度 |
| 磁石被移除 | 标记失效；不自动传送到世界出生点 |
| 目标越界 | 在区块加载前拒绝 |
| 落脚位不足 | 全队留在原地，不拆分传送 |
| 灵性不足 | 不移动任何成员 |
| 主持者冷却 | 显示剩余秒数 |
| 乘客冷却 | 该乘客不加入，不影响其他合格成员 |
| 中途传送失败 | 尝试全员回滚并返还灵性 |

管理员无需编辑 NBT。玩家可先输入 `/pm travel` 判断标记是否有效；磁石丢失时在原位置重新放置磁石即可让同一指南针恢复有效。

## 7. 自动化验证

`M3TravelNetworkLogicTest` 和 `TravelMarkerServiceTest` 覆盖：

- 0–3 人费用和越界人数钳制；
- 潜行同意、同维度、同标记、半径和冷却门禁；
- 死亡、旁观、睡眠、NaN 与无限距离拒绝；
- 原版磁石 NBT 的维度/坐标解析；
- 非法维度、缺失坐标和缺失字段拒绝。

第 11 项 Forge GameTest 在真实 `ServerLevel` 中搭建物理地面和磁石，验证：

- 磁石不存在时失败且灵性、冷却、位置不变；
- 一名主动同行者成功抵达，总消耗精确为 90；
- 未潜行旁观者留在原地；
- 指南针不被消耗；
- 抵达保护生效；
- 冷却重试不重复扣费。
